## 四、KeydroidxWidgetAppPickerFragment 设计

### 1. 模式区分（Bundle）

- `mode=ADD`：从 S6 选「应用」进入，标题「选择应用」，确认键 → `addWidget` → `exitCurrent`
- `mode=EDIT, editIndex=N`：从 S1 应用组件确认键进入，标题「更换应用」，
  确认键 → `updateWidget(editIndex, …)` → `exitCurrent`
- `editIndex` 越界时降级为 ADD 模式。

### 2. 数据加载（混排、按名称排序、不分组）

- 安卓应用：`PackageManager.queryIntentActivities(ACTION_MAIN + CATEGORY_LAUNCHER)`（同步）
- J2ME 应用：读取 `J2ME-apps.db`，`AppItemDao.getAllSingle(SimpleSortQuery)`（RxJava 异步，参考 `KeydroidxShortcutSettingsFragment`）
- 先构建安卓宫格，J2ME 加载完成后合入并刷新；DB 不存在则静默跳过
- 应用身份 key：
  - 安卓：`packageName/className`（存 widget.value）
  - J2ME：`j2me:label:pathExt`（存 widget.value，兼容 ShortcutSettings 的 className 劫持）
- 已添加集合：`storage.getWidgets()` 中 TYPE_APP 的 `.value` 集合

### 3. 宫格规格

- 列数：`clamp(3, floor(availWdp/72), 5)`（availWdp = 设计基准宽 240dp）
- 行数：复用 `KeydroidxMenuFragment.computeRowsPerPage()` 反推思路，
  `rows = clamp(3, floor((availDesign - 预留头部高度) / 64), 8)`，行高均分拉伸
- 格子：图标 36×36dp（`setFilterBitmap(false)`）+ 名称 9sp 单行省略，选中 `bg_nokia_selected_dark`
- 每页 `perPage = columns × rowsPerPage`，页码 `tvAppPage`（如 1/3）
- 通过 `host.getScale()` 取 scale、`host.getMidPanelHeight()` 取 panelH；尺寸一律 `KeydroidxDimens.dp()`

### 4. 已添加 / 当前编辑项标记

- 已添加：图标 alpha≈0.3、文字灰 `#666666`、浅灰底；光标可路过，确认键无响应
- 当前编辑项（仅 EDIT）：正常彩色 + 浅蓝底 + 右上角 📌 角标；光标初始定位在此格；确认键无响应
- 其余未添加应用：正常，确认键添加/更换

### 5. 搜索功能（两步激活）

- 搜索框作为宫格外的「特殊格子」参与方向键导航：
  - 宫格第一行按上 → 焦点移到搜索框（蓝色高亮）
  - 搜索框按 上/下 → 焦点回宫格第一行
  - 搜索框按确认键 → 激活 EditText + 弹出软键盘（编辑态）
- 编辑态：`TextWatcher` 实时过滤（包含匹配、不区分大小写）；
  显示「匹配 X 个应用」；IME 完成键 → 关闭软键盘 + 焦点回宫格第一行；
  BACK → 关闭软键盘、焦点留在搜索框；右软键 → 关闭软键盘 + 返回
- 清空搜索文字 → 恢复完整列表
- 触屏：搜索框点击 = 确认键激活；宫格点击 = 选中

### 6. 宫格导航（不环绕）

- 上：同列上移；第一行 → 搜索框（不做 pagePrev）
- 下：同列下移；最后一行 → 翻下一页（保持同列）
- 左/右：同行移动；到最左/最右 → 不动（不回绕，override KeydroidxMenuFragment 的回绕行为）
- 确认键：选中可用应用 → add/update → 返回；已添加/当前编辑项不响应
- 触摸滑动：上滑/左滑 → 下一页；下滑/右滑 → 上一页（参考 KeydroidxMenuFragment）

### 7. KeydroidxPage / KeydroidxFocusHost

- `getPageTitle()`：ADD=「选择应用」、EDIT=「更换应用」
- `getSoftLeftText()`：null（隐藏）
- `getSoftRightText()`：「返回」
- `onSoftRight()` / `onBack()` → 编辑态先关软键盘，再 `exitCurrent()`
- 底部栏统一走 `host.refreshPageBar()`，禁止直接操作 bottomBar TextView；
  禁止给软键加高亮/焦点逻辑

### 8. 键盘与软键盘注意

- 编辑态用 `InputMethodManager.showSoftInput()`；`windowSoftInputMode` 保持现状（不新增 adjustResize）
- 方向键经 `KeydroidxDesktopActivity.dispatchKeyEvent` → `KeydroidxFocusHost` 分发，无需写死 keyCode
- 编辑态期间宫格方向键仍可导航（切到宫格时 EditText 自动失焦、软键盘收起）

## 七、真机验证记录（4a24ecf 240×320，SDK 19）

> **release 版无新代码**；本次全部验证在 debug 版进行。曾因 debug 版 `nokia_key_bindings.xml`

### 验证通过项

- **导航链路**：右软键(桌面设置) → 下×2(桌面组件) → 确认 → S1 桌面组件设置 ✓
- **S2 选项弹窗**：左软键「选项」→ 确认「添加组件」→ S6 类型选择页 ✓（canAdd=true）
- **ADD 模式**：
  - S6 确认「应用」→ AppPicker（标题「选择应用」）✓
  - 宫格 columns=3 rowsPerPage=3 perPage=9，安卓 20 + J2ME 1 = 21 项，3 页 ✓
  - 方向键导航正常（setFocusPos 日志确认：0→1→…）✓
  - 确认选中 → `addWidget` 保存 + Toast「已添加」→ **回 S1** ✓
- **EDIT 模式**：
  - S1 确认应用类组件 → AppPicker（「更换应用」，mode=EDIT editIndex=0）✓
  - 当前编辑项不可选（确认键消费），换绑另一应用 → `updateWidget` + Toast「已更换」→ **回 S1** ✓

### 测试中发现并修复的问题

1. **ADD 模式确认后回 S6 而非 S1**：`exitCurrent()` 只 pop 一层返回栈（栈为 S1→S6→AppPicker）。
   设计文档要求 ADD 确认回 S1。修复：`confirmSelection()` ADD 分支改用
   `FragmentManager.popBackStackImmediate()` 同步 pop 两层；EDIT 分支仍 exitCurrent() 一层。
2. **EDIT 模式 J2ME 编辑项定位时序 bug**：`setInitialFocus()` 在 J2ME 异步加载完成前执行，
   此时 filtered 只有安卓应用 → 找不到 J2ME 编辑项 → fallback focusPos=0；J2ME 完成后再次调用时
   因「已定位过焦点」跳过，导致永远无法定位到 J2ME 编辑项。
   修复：新增 `editLocateDone` 标志，J2ME 加载完成前不标记已完成，加载后重试定位成功
   （日志：`EDIT 初始光标定位到当前编辑项 i=2 page=1/3 focusPos=2`）。
3. **补充缺失日志**：`onDirection` 各分支、`setFocusPos`、搜索框聚焦态均补 `KeydroidxLog` 输出，
   符合 CODEBUDDY.md「尽可能多日志」要求（此前方向键无任何日志，排障困难）。
