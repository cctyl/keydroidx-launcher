# 原键桌面 — 桌面组件系统设计计划

## 一、设计目标

桌面组件区域（原 notificationArea）从**写死4项**改造为**可配置、可排序、可增删**的通用组件系统。

- 支持多种组件类型，用户自由组合
- 组件数量上限 15 个，超出区域垂直滚动
- 支持方向键导航，选中高亮
- 设置界面可增删改排序

---

## 二、支持的组件类型（共 6 种）

| 类型 | 图标 | 点击行为 | 可配置项 | 示例 |
|------|------|---------|---------|------|
| **应用** | 应用自带图标 | 启动应用 | 从应用列表选择 | 音乐播放器、微信 |
| **网址** | 🌐 | 浏览器打开 | 网址、显示名 | 3g.qq.com、百度 |
| **日历** | 📅 | 打开日历App | 无 | 显示"星期三 7月29日"+下条日程 |
| **Activity快捷** | 应用图标 | 启动指定Activity | 选应用→选Activity | 微信扫一扫、支付宝付款码 |
| **内存信息** | 📊 | 无（纯显示） | 无 | "RAM: 2.1G/4G" |
| **存储信息** | 💾 | 无（纯显示） | 无 | "存储: 45G/128G" |
| **使用时长** | ⏱️ | 无（纯显示） | 无 | "今日: 3h 24m" |

> 注：内存/存储/时长这三个是**纯显示组件**，不可点击，无动作。
>
> **系统功能（锁屏、WiFi、蓝牙、手电筒、飞行模式等）已从桌面组件系统中移出，
> 独立为「快捷开关」功能，详见 `docs/5-快捷开关功能设计.md`。**

## 四、桌面显示层设计

### 4.1 布局改动

```
fragment_nokia_desktop.xml 改动：

notificationArea（原LinearLayout）→ ScrollView + LinearLayout

- 快捷栏（shortcutBar）不变
- 分割线不变
- 组件区域改为可垂直滚动
  - 每个组件行高度固定（约28dp）
  - 纯显示组件：左侧图标 + 文字
  - 可点击组件：左侧图标 + 文字 + 右侧箭头提示（可选）
  - 选中时整行高亮（bg_nokia_selected）
- 超出可视区域自动滚动
```

### 4.2 焦点导航

```
桌面待机屏焦点体系：

快捷栏（横向） ←→ 组件区域（纵向）

方向键行为：
- 上：组件区域内上移一项；如果在第一项再上移→快捷栏最后一项
- 下：组件区域内下移一项；如果在最后一项再下移→快捷栏第一项
- 左：如果在组件区域→跳到快捷栏最后一项
- 右：如果在组件区域→跳到快捷栏第一项
- 快捷栏内左右：在图标间切换（现有逻辑）
```

### 4.3 纯显示组件样式

```
内存/存储/时长 三个指示条：

♦ RAM: 2.1G / 4G          [进度条可视化■■□□]
♦ 存储: 45G / 128G        [进度条可视化■■■■□□□□]
♦ 今日: 3h 24m            [无进度条]

- 图标用简单符号或小型图标
- 文字用较小字号（10sp）
- 进度条用纯色填充（如蓝色/绿色）
- 整行不可点击，无焦点高亮（或高亮但无动作）
```

## 九、使用时长统计实现

```
实现方式：
1. 使用 UsageStatsManager 查询今日屏幕使用时间
2. 需要 PACKAGE_USAGE_STATS 权限（用户手动授权）
3. 未授权时显示"未授权"或引导用户开启
4. 每次桌面显示时刷新数据

数据格式：
- 小于1小时："今日: 23m"
- 大于1小时："今日: 3h 24m"
```

## 十二、Android 版本兼容性策略

项目 `minSdk=14`（Android 4.0），`targetSdk=34`。各功能模块需按以下策略处理版本差异。

### 总原则

1. **尽量兼容**：能用旧 API 实现的，写版本分支，全版本可用
2. **不能兼容的隐藏**：依赖高版本系统 API 且无替代方案的功能，在低版本上隐藏入口
3. **统一用 `Build.VERSION.SDK_INT` 判断**：不使用反射或 try-catch 探测 API
4. **图标颜色统一用 `setColorFilter()`**：不使用 API 21+ 的 `setTint()`
5. **矢量图加载统一用 `app:srcCompat` / `ContextCompat.getDrawable()`**：不使用 `android:src` / `getResources().getDrawable()`（API 19 崩溃）
6. **新建布局根标签必须声明 `xmlns:app`**：所有新建 XML 布局文件都需补充 `xmlns:app="http://schemas.android.com/apk/res-auto"`

### 各功能兼容性矩阵

| 功能 | 最低可用 API | Android 4.4 (API 19) | 处理方式 | 详见文档 |
|------|------------|---------------------|---------|----------|
| 应用组件 | 1 | ✅ | — | 2号文档 |
| 网址组件 | 1 | ✅ | — | 3号文档 |
| 日历组件 | 1 | ✅ | — | 4号文档 |
| 内存信息组件 | 1 | ✅ | — | 4号文档 |
| 存储信息组件 | 1 | ✅ | API < 18 用旧 `StatFs` 方法 + long 强转 | 4号文档 §8.2 |
| Activity快捷组件 | 1 | ✅ | — | 6号文档 |
| **使用时长组件** | **21** | ❌ | S6 类型选择页灰色不可选；已添加的显示不兼容提示 | 4号文档 §8.1 |
| WiFi 开关 | 1 | ✅ | API 29+ 降级为跳转设置页 | 5号文档 §13 |
| 蓝牙开关 | 5 | ✅ | — | 5号文档 §13 |
