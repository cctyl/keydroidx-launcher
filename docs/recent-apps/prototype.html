最近任务 Recent Apps

功能机风格的「最近任务」界面：2 列卡片网格展示最近使用的应用，确认键把目标应用拉回之前的界面（恢复而非重启）， 并支持保护名单与清理后台。严格对齐 NOKIA_DEVELOPMENT_RULES.md、guide/07-dialogs.md、 typography-and-font-spec.md 与 FEATURE_PHONE_UI_SPEC.md。

画布 240 × 320 卡片 2 列 / 56dp 0 键 一键清理未保护 选项 保护此应用 / 取消保护 面板 底部锚定 + 上方压暗 ≤13sp 一律不加粗

按键与保护规则

上下 / 左右移动卡片焦点（2 列网格，跨列换行）
确认键恢复焦点应用 → 回到它之前的界面（不重启）
左软键选项菜单（打开 / 保护 / 清理…）
右软键退出返回桌面
返回键先关面板，再退出页面
数字键 0一键清理未保护后台（先弹确认）
长按过滤连发：仅首次按下生效，方向键放行

保护名单语义（与「后台管理」共用一份）

  • 加入方式：选项 →「保护此应用」，立即生效并持久化到 KeydroidxSettingsStorage 保护名单。
  • 保护效果：0 键一键清理 / 清理全部后台 自动跳过已保护的应用。
  • 手动清理：「清理此任务」不受保护名单限制，可单独清理已保护的应用（会先弹确认）。
  • 状态可见：卡片右上角绿色盾牌 + 绿色描边；摘要行显示「未保护 N · 已保护 M」。
  • 恢复语义：确认键重新下发该应用启动 Intent，系统把已存在的任务栈拉回前台 → 回到它之前的界面（不重建栈顶 Activity）；任务已被系统回收时才会冷启动。
