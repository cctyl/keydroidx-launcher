# 桌面「正在播放」音乐组件设计文档

> 功能：在 KeydroidX 桌面组件区新增「正在播放」组件，跨进程实时显示音乐播放器的当前歌曲、歌手、当前歌词行与播放进度；按确认键/点击进入音乐播放详情页。
>
> 关联仓库：
> - 本仓库（桌面侧）：`keydroidx-launcher`
> - 音乐播放器（数据源侧）：`keydroidx-music`，其 `docs/WIDGET_DESIGN.md` 为该功能的完整双端设计文档

---

## 1. 功能定位与架构

桌面组件区只渲染**原生组件**（`NokiaWidgetItem` 行布局），**不接入 `AppWidgetHost`**。音乐 App 通过导出的 `ContentProvider` 暴露播放态，桌面侧新增一个原生组件类型读取该数据并自渲染，天然复用现有焦点导航、点阵字体与主题样式。

数据流：

```
[音乐App] PlaybackStateManager(StateFlow)
   │  广播 ACTION_PLAYBACK_CHANGED + contentResolver.notifyChange(PLAYBACK_URI)
   ▼
[音乐App] PlaybackProvider (content://io.github.cctyl.keydroidx.music.playback/state)
   ▲
   │ ContentObserver 监听 + 主动 query
[桌面] NokiaDesktopFragment.createMusicPlayerWidgetRow()
   │ 确认键/点击
   ▼
[音乐App] MusicPlayerActivity（黑胶唱机详情页）
```

---

## 2. 数据接口（音乐 App 侧，只读）

**Provider URI**：`content://io.github.cctyl.keydroidx.music.playback/state`

| 列名 | 类型 | 说明 |
|------|------|------|
| `song_id` | Long | 歌曲 ID |
| `title` | String | 歌曲标题 |
| `artist` | String | 歌手名 |
| `album_art_uri` | String | 专辑封面 URL |
| `is_playing` | Int | 0/1 是否正在播放 |
| `position_ms` | Long | 当前播放位置 (ms) |
| `duration_ms` | Long | 歌曲总时长 (ms) |
| `lyric_text` | String | 当前歌词行文本（无歌词为空） |
| `updated_at` | Long | 数据更新时间戳 (ms) |

**变更通知**：音乐 App 播放状态变化时 `notifyChange(PLAYBACK_URI)`，桌面侧 `ContentObserver` 收到回调即刷新。

## 3. 桌面侧实现

### 3.1 新增组件类型 `TYPE_MUSIC_PLAYER = 11`

文件：`app/src/main/java/ru/playsoftware/j2meloader/nokia/NokiaWidgetItem.java`

```java
public static final int TYPE_MUSIC_PLAYER = 11; // 正在播放（音乐播放器状态，不可编辑）
public static final int TYPE_COUNT = 12;
```

新增元数据：
- `getTypeName(11)` → `"正在播放"`
- `getDefaultLabel(11)` → `"正在播放"`
- `getTypeTag(11)` → `"[音乐]"`
- `getTypeIconUnicode(11)` → `NokiaIcons.ICON_MUSIC_NOTE`
- `getTypeIcon(11)` → `R.drawable.ic_nokia_music`
- `isEditable()` → `false`（不可编辑）

### 3.2 图标

- `NokiaIcons.java` 新增 `ICON_MUSIC_NOTE = "\ue405"`（Material Icons 音符）
- 新增矢量图标 `app/src/main/res/drawable/ic_nokia_music.xml`（白色音符）

### 3.3 组件行渲染

文件：`app/src/main/java/ru/playsoftware/j2meloader/nokia/NokiaDesktopFragment.java`

`createWidgetRow()` 新增分支，委托 `createMusicPlayerWidgetRow(item)` 创建行：

布局结构（横向）：
```
[♫音符图标] [文本列: 歌名-歌手] [进度条]
            [文本列: 当前歌词行]
```

- **第一行**：`getMusicWidgetTitle()` —— 查询 Provider 得 `title - artist`，若 `is_playing=0` 追加 `[暂停]`；无歌曲显示 `"音乐播放器（未播放）"`
- **第二行**：`getMusicWidgetLyric()` —— 当前歌词行，无歌词显示 `"暂无歌词"`
- **进度条**：`getMusicWidgetProgressRatio()` —— `position_ms / duration_ms`，横条填充

三个取数方法均通过 `getContext().getContentResolver().query(MUSIC_PLAYBACK_URI, ...)` 同步读取（Provider 仅读内存 StateFlow，无 I/O）。

### 3.4 实时刷新（ContentObserver）

桌面侧定义常量与观察者：

```java
private static final Uri MUSIC_PLAYBACK_URI =
        Uri.parse("content://io.github.cctyl.keydroidx.music.playback/state");
private final ContentObserver musicPlaybackObserver = new ContentObserver(new Handler(Looper.getMainLooper())) {
    @Override public void onChange(boolean selfChange, Uri uri) {
        if (!isAdded() || getView() == null) return;
        rebuildMusicWidgetRowOnly(getView());
    }
};
```

- `onResume()` → `registerMusicPlaybackObserver()`
- `onPause()` → `unregisterMusicPlaybackObserver()`
- `rebuildMusicWidgetRowOnly()`：**仅重建音乐组件行**（`removeViewAt` + `addView` 原位替换），并同步更新 `focusTargets` 对应索引，**保持焦点不丢失**、其余组件不动。

### 3.5 确认键 / 点击行为

`setupWidgetRowClick()` 新增 `TYPE_MUSIC_PLAYER` 分支 → `launchMusicPlayer()`：

```java
Intent intent = new Intent(Intent.ACTION_MAIN);
intent.setClassName("io.github.cctyl.keydroidx.music",
        "io.github.cctyl.keydroidx.music.ui.MusicPlayerActivity");
intent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK);
startActivity(intent);
```

音乐 App 未安装时捕获异常并 Toast 提示。

### 3.6 类型选择页

文件：`app/src/main/java/ru/playsoftware/j2meloader/nokia/NokiaWidgetTypePickerFragment.java`

`TYPE_IDS` 数组追加 `NokiaWidgetItem.TYPE_MUSIC_PLAYER`。`onTypeSelected()` 落入默认分支（直接添加并返回 S1），无需额外跳转。

### 3.7 包可见性

`app/src/main/AndroidManifest.xml` `<queries>` 新增：

```xml
<package android:name="io.github.cctyl.keydroidx.music" />
```

> 音乐 App 的 `MusicPlayerActivity` 已设为 `android:exported="true"`，桌面侧才能通过显式 Intent 跨进程启动。

## 5. 交互流程

```
桌面待机屏 → UP/DOWN 移到「正在播放」行
  → 行高亮（青色背景+白字加粗），显示：
      ♫ 顺风顺水 - 邹念慈/繁星合唱团
      ♪ 风起的时候 谁在等候     ← 后台实时歌词
      ━━━━━━━━━━━━━━            ← 进度条
  → 按确认键 → 打开 MusicPlayerActivity
  → 右软键返回桌面，焦点回到该行
```

## 6. 兼容性与降级

| 场景 | 行为 |
|------|------|
| 音乐 App 未安装 | 组件点击 Toast「未安装音乐播放器」 |
| 已安装但未播放 | 显示「音乐播放器（未播放）」 |
| 音乐 App 进程未运行 | Provider 返回空状态，显示未播放 |
| 无歌词 | 显示「暂无歌词」 |
| 播放暂停 | 标题行追加 `[暂停]` |
