# 挂机键行为定义（行为矩阵 + 状态机 + 实测验证）

> 文档性质：**挂机键（红键）行为唯一权威定义**。与《电源键拦截方案设计.md》的关系：本文档只定义**行为矩阵与状态语义**（做什么），拦截方案文档只定义**技术实现链路**（怎么做，evdev grab + 注入）。两文档配套阅读，行为以本文档为准。
>
> 状态：行为矩阵已经用户逐条确认；抽象状态机为对矩阵的一致性归纳（已与全部 8 个场景核对无矛盾）。落地实现后需按第 7 节逐项实测校准。

## 1. 术语约定

- **挂机键**：物理电源键（`KEY_POWER`，keyCode=116）以及可能包含的 HOME 键，在诺基亚语义下被重定义为「红键/挂机键」。
- **回桌面**：切回**诺基亚桌面主界面**（待机屏）。**不改变屏幕亮灭**（亮屏回桌面仍亮着）。
- **锁屏**：系统锁屏（Keyguard）。**与熄屏同时发生**（锁屏即熄屏）。
- **唤醒**：在**息屏**态按下后点亮屏幕，**显示锁屏界面待解锁**（不直接进入桌面）。
- **解锁**：用户在锁屏界面的操作（滑动/密码），解锁后进入「原本界面」（见第 6 节）。

## 2. 界面分层（行为判定只认这 4 类）

| 界面 | 含义 |
|------|------|
| **诺基亚桌面主界面（待机屏）** | 应用启动后显示的第一个界面（`NokiaDesktopActivity` 待机屏） |
| **诺基亚桌面其他界面** | 功能表 / 设置 / 百宝箱等桌面子页面 |
| **锁屏界面** | 系统 Keyguard（含息屏唤醒后短暂显示的解锁页） |
| **非诺基亚应用** | 除诺基亚桌面外的任意第三方/系统应用 |

## 3. 行为矩阵（用户确认版：8 场景 × 连续按下 3 次）

> 约定：**第 N 次按的前置状态 = 第 N-1 次按后的结果状态**（若矩阵注明"解锁后…"则视为已完成解锁、界面已稳定后的状态）。

| # | 场景 | 第 1 次按 | 第 2 次按 | 第 3 次按 |
|---|------|-----------|-----------|-----------|
| 1 | 亮屏 + 任意非诺基亚应用 | 回诺基亚桌面 | 锁屏 | 亮屏，显示锁屏界面，解锁后显示诺基亚桌面 |
| 2 | 息屏 + 任意非诺基亚应用 | 亮屏，显示锁屏界面，解锁后显示原本的应用 | 回诺基亚桌面 | 锁屏 |
| 3 | 亮屏 + 诺基亚桌面待机屏 | 锁屏（熄屏） | 亮屏，显示锁屏界面，解锁后显示诺基亚桌面 | 锁屏（熄屏） |
| 4 | 息屏 + 诺基亚桌面待机屏 | 亮屏，显示锁屏界面，解锁后显示诺基亚桌面 | 锁屏（熄屏） | 亮屏，显示锁屏界面，解锁后显示诺基亚桌面 |
| 5 | 亮屏 + 诺基亚桌面其他界面（功能表/设置/百宝箱） | 回到桌面待机屏（不锁屏） | 锁屏（熄屏） | 亮屏，显示锁屏界面，解锁后显示诺基亚桌面 |
| 6 | 息屏 + 诺基亚桌面其他界面（功能表/设置/百宝箱） | 亮屏，显示锁屏界面，解锁后显示诺基亚桌面其他界面 | 回诺基亚桌面主界面 | 锁屏（熄屏） |
| 7 | 亮屏 + 锁屏界面 | 锁屏（熄屏） | 亮屏，显示锁屏界面，解锁后原本显示什么就显示什么 | 回诺基亚桌面主界面 |
| 8 | 息屏 + 锁屏界面 | 亮屏，显示锁屏界面，解锁后原本显示什么就显示什么 | 回诺基亚桌面主界面 | 锁屏 |

## 4. 抽象状态机（对矩阵的一致性归纳）

全部 8 个场景可归纳为 **5 个基态 + 4 条转移**，每条转移对应一个「原子动作」：

| 基态 | 屏幕 | 前台 | 按挂机键 → | 动作 |
|------|------|------|-----------|------|
| **A** 亮屏·非诺基亚应用 | 亮 | 其他应用 | 回诺基亚桌面主界面 → **C** | 回桌面（不熄屏） |
| **B** 亮屏·诺基亚桌面其他界面 | 亮 | 功能表/设置/百宝箱 | 回诺基亚桌面主界面 → **C** | 回桌面（不熄屏） |
| **C** 亮屏·诺基亚桌面主界面（待机屏） | 亮 | 待机屏 | 锁屏（熄屏） → **E** | 锁屏+熄屏 |
| **E** 息屏（任意前台） | 灭 | 黑屏 | 唤醒，显示锁屏界面 → **F** | 点亮+锁屏界面 |
| **F** 亮屏·锁屏界面 | 亮 | Keyguard | 锁屏（熄屏） → **E** | 再次熄屏 |

转移图：

```
        [A/B 亮屏·非主界面]
            │ 按挂机键：回诺基亚桌面主界面（不熄屏）
            ▼
        [C 亮屏·主界面(待机屏)]
            │ 按挂机键：锁屏 + 熄屏
            ▼
        [E 息屏]
            │ 按挂机键：唤醒，显示锁屏界面
            ▼
        [F 亮屏·锁屏界面] ──按挂机键──▶ E（再次熄屏）
            │ 解锁：回到进入锁屏前的前台界面
            └────────────────▶ A / B / C（取决于锁屏前的前台）
```

**循环语义**：每次按下都产生一个新状态，下一次按下按**新状态**的规则处理，无终止。连续按 N 次即沿转移图走 N 步（如场景 1：A→C→E→F→解锁回 A，循环）。

## 5. 核心语义规则（实现时必须遵守）

1. **回桌面不改变亮灭屏**：只在「亮屏 + 非主界面」触发，目标恒为诺基亚桌面主界面。
2. **锁屏 = 熄屏，两者同时发生**；且**锁屏动作只从「亮屏 + 诺基亚桌面主界面」触发**（其他状态不注入锁屏）。
3. **锁屏界面态按挂机键 = 再次熄屏**（行为上等价"再锁一次"，转移回 E）。
4. **唤醒只在「息屏」态触发**：点亮后显示锁屏界面待解锁，**不直接进入桌面**；解锁后回到「原本界面」。
5. **解锁后「原本界面」= 进入息屏/锁屏前的最后前台界面**（见第 6 节）。
6. **状态判定只认两维**：屏幕亮灭（`dumpsys power` 的 Awake/Asleep）+ 前台界面归属（本应用 / 本应用子界面 / 其他应用 / Keyguard）。前台归属的探测见《电源键拦截方案设计.md》第 4.2 节。

## 6. 解锁后「原本界面」的判定

「原本界面」= **进入 E（息屏/锁屏）状态前的最后前台界面**。各场景实例：

| 场景 | 进入息屏前的前台 | 解锁后显示 |
|------|-----------------|-----------|
| 2（息屏+非诺基亚应用） | Settings 等应用 | 原本应用 |
| 4（息屏+待机屏） | 诺基亚桌面待机屏 | 诺基亚桌面（待机屏） |
| 6（息屏+桌面子界面） | 功能表/设置/百宝箱 | 对应子界面 |
| 1/3/5 的锁屏段（锁屏时前台=待机屏） | 待机屏 | 诺基亚桌面 |

> 关键点：**息屏时不管前台是什么，第 1 次按都是「点亮 + 锁屏界面」，解锁后回到原本界面**——屏幕亮灭优先于前台界面参与判定。

## 7. adb 实测验证步骤

### 7.1 前置条件

```bash
# 1. 构建安装 debug 包
.\build_install_debug.bat <serial>

# 2. 启动 mini_shizuku 服务端
adb -s <serial> shell "sh /data/local/tmp/mini_shizuku.sh"

# 3. 桌面设置 → mini_shizuku → 挂机键拦截 → 开启

# 4. 确认回放模式（必须看到 uinput replay device created）
adb -s <serial> logcat -d -s MiniShizuku:* Interceptor:*
# 期望：Found KEY_POWER / uinput replay device created / Interceptor started successfully
```

### 7.2 按键注入方式（关键区分）

| 方式 | 命令 | 是否触发 evdev 拦截 |
|------|------|--------------------|
| **物理按键** | 人手按挂机键 | ✅ 是（首选） |
| sendevent 写设备（需 root） | `adb shell sendevent /dev/input/event1 1 116 1` 与 `... 1 116 0`（EV_KEY / KEY_POWER） | ✅ 是（走 evdev） |
| input keyevent 合成 | `adb shell input keyevent 26` | ❌ 否（InputManager 合成，绕过 evdev） |

> ⚠️ **验证拦截分支必须用物理按键（或 root 下 sendevent）**。`input keyevent` 是系统层合成注入，不会被 grab 拦截，只能用于验证「注入动作本身」与系统原生行为，不能验证拦截后的状态机。

### 7.3 场景进入方法

```bash
# 亮屏 + 非诺基亚应用（场景1/2）
adb shell input keyevent KEYCODE_WAKEUP && adb shell am start -n com.android.settings/.Settings

# 亮屏 + 诺基亚桌面主界面（场景3/4）
adb shell am start -n io.github.cctyl.nokia.debug/ru.playsoftware.j2meloader.nokia.NokiaDesktopActivity

# 亮屏 + 诺基亚桌面其他界面（场景5/6）：主界面按左软键进功能表
adb shell input keyevent KEYCODE_MENU

# 亮屏 + 锁屏界面（场景7）：先熄屏再唤醒，不解锁
adb shell input keyevent KEYCODE_POWER      # 熄屏（注入，用于准备场景）
adb shell input keyevent KEYCODE_WAKEUP     # 唤醒，显示 Keyguard（若 ROM 不支持则物理按键）

# 息屏（场景2/4/6/8 的准备）
adb shell input keyevent KEYCODE_POWER      # 或等自然超时

# 解锁（模拟解锁）
adb shell wm dismiss-keyguard               # 部分 ROM 有效；否则人工滑动
```

### 7.5 验收标准

1. 任意应用按挂机键回诺基亚桌面（不熄屏）；桌面主界面再按锁屏+熄屏；熄屏后按唤醒显示锁屏界面；锁屏界面按=再次熄屏。
2. 解锁后总是回到「进入锁屏前的原本界面」。
3. 音量键全程正常（回放模式不吞键）。
4. 连续按键 20 次无崩溃、无注入风暴；开关状态不漂移。
5. 关闭「挂机键拦截」后，挂机键恢复系统默认行为（休眠/关机菜单）。
