# 3-网址类组件添加/编辑界面设计

> 本文档定义网址类组件的表单填写界面（`KeydroidxWidgetUrlEditFragment`）。
> 同一界面通过 Bundle 参数区分**添加模式**与**编辑模式**。
> 包含两个文本输入字段 + 保存按钮，均支持方向键导航。

---

## 一、界面层级关系

同一 `KeydroidxWidgetUrlEditFragment` 通过 `arguments` 参数区分两种模式：

```
【添加模式】
S6 选择组件类型 → 选「网址」
  └─ 网址编辑界面 (KeydroidxWidgetUrlEditFragment, mode=ADD)
       └─ 填写名称 + 网址 → 左软键保存 → addItem() → 回到 S1
       └─ 右软键 → 回到 S6（不保存）

【编辑模式】
S1 桌面组件设置 → 确认键（光标在网址类组件上）
  └─ 网址编辑界面 (KeydroidxWidgetUrlEditFragment, mode=EDIT, editIndex=N)
       内容预填当前值
       └─ 修改名称或网址 → 左软键保存 → updateItem() → 回到 S1
       └─ 右软键 → 回到 S1（不保存）
```

## 二、界面布局

```
┌──────────────────────────────────┐
│ 添加网址                          │  ← 标题（编辑模式显示「编辑网址」）
│                                  │
├──────────────────────────────────┤
│                                  │
│  名称                            │  ← 字段标签
│ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓   │  ← 名称字段获得焦点（蓝色高亮边框）
│ ▓ 3g.qq.com                  ▓▓   │    光标在此，但 EditText 未激活
│ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓   │
│                                  │
│  网址                            │  ← 字段标签
│ ┌────────────────────────────┐   │  ← 网址字段无焦点（浅色边框）
│ │ https://3g.qq.com          │   │
│ └────────────────────────────┘   │
│                                  │
│     ┌──────────┐                 │
│     │   保存   │                 │  ← 保存按钮（焦点目标）
│     └──────────┘                 │
│                                  │
├──────────────────────────────────┤
│ 保存                            返回│
└──────────────────────────────────┘
```

### 布局要素

| 区域 | 设计 |
|------|------|
| **标题** | 添加模式：「添加网址」；编辑模式：「编辑网址」 |
| **字段标签** | 灰色小字（`#AAAAAA`），如「名称」「网址」 |
| **字段值** | 白色文字，等宽感或正常字体；空时显示灰色占位符 |
| **字段焦点** | 蓝色高亮边框（`bg_nokia_selected_dark` 或自定义 border drawable） |
| **激活态** | 确认键后 EditText 获得焦点 → 系统光标闪烁 + 软键盘弹出 |
| **保存按钮** | 居中，诺基亚风格按钮（深色底 + 蓝色文字/边框），可被方向键选中 |
| **底部软键** | 左「保存」、中（空）、右「返回」 |

## 三、焦点导航

本界面有 3 个可聚焦目标，按上下键依次导航：

```
  名称字段     ← focusIndex=0
  网址字段     ← focusIndex=1
  [保存] 按钮  ← focusIndex=2
```

| 方向 | 行为 |
|------|------|
| 上 | 移到上一个焦点目标；已在第一个时不动 |
| 下 | 移到下一个焦点目标；已在最后一个时不动 |
| 左/右 | 无效果（线性纵向列表） |

**焦点视觉**：

| 目标 | 无焦点状态 | 焦点态（未激活编辑） |
|------|-----------|-------------------|
| 名称/网址字段 | 浅灰色边框（`#444`），背景透明 | 蓝色高亮边框（复用 `bg_nokia_selected_dark` 或 drawable） |
| 保存按钮 | 浅灰文字 + 浅灰边框 | 蓝色高亮文字 + 蓝色边框 |

## 四、文本字段的交互

名称和网址两个字段的交互逻辑一致，复用搜索框的三态模式（参考 2 号文档第六章）：

### 三态切换

```
  焦点态 ──确认键──→ 编辑态 ──回车/完成──→ 焦点态
    ↑                  │
    │                  │ 物理返回键
    │                  ↓
    │              焦点态（软键盘收起）
    │
    └── 上/下键 → 移到上一个/下一个焦点目标
```

### 焦点态（蓝色高亮但 EditText 未激活）

| 按键 | 行为 |
|------|------|
| 上 | 移到上一个焦点目标 |
| 下 | 移到下一个焦点目标 |
| 确认键 | 激活 EditText → 系统光标闪烁 + 软键盘弹出 |
| 左/右 | 无效果 |
| 左软键 | 保存并返回 |
| 右软键 | 取消返回 |

> ⚠️ **按键配对规范（DOWN/UP 成对消费）**：本编辑页由 S1 确认键进入、焦点态确认键激活 EditText（进入编辑态），这两处确认键 DOWN 若在 `KeydroidxDesktopActivity.dispatchKeyEvent` 本层被消费，须同步消费对应的 UP（含 REPEAT），禁止只消费 DOWN。否则 DOWN 被吞、UP 穿透到新页面的可点击 View 时，UP 会合成 `performClick()` 触发第二次动作（例：进入编辑页后又自动激活某字段）。实现用 `lastHandledDownKeyCode` 记录被本层消费的 keyCode，非 DOWN 分支对相同 keyCode `return true` 吞掉，未消费键 DOWN 路径复位为 `KEYCODE_UNKNOWN`。EditText 真正激活后的按键走系统软键盘，不受此约束。

### 编辑态（EditText 激活，软键盘弹出）

| 用户操作 | 行为 |
|---------|------|
| 软键盘输入 | 正常输入文本 |
| 软键盘回车/完成键 | 关闭软键盘，回到焦点态（焦点留在当前字段） |
| 物理返回键 | 关闭软键盘，回到焦点态 |
| 右软键 | 关闭软键盘 + **保存** + 回到 S1 |

> 编辑态期间上/下方向键不导航——它们可能在软键盘上被消费，
> 或者需要先关闭软键盘再导航。因此：
> 编辑态时，上/下/左/右 = 无效果（焦点锁定在 EditText 内）。
> 用户通过回车/完成键或返回键退出编辑态后，才能继续导航。

### 字段约束

| 字段 | 最大长度 | 允许为空 | 占位符 |
|------|---------|---------|--------|
| 名称 | 20 字符 | **否**（保存时校验） | 「输入显示名称」 |
| 网址 | 200 字符 | **否**（保存时校验） | 「输入网址，如 https://...」 |

> 网址字段的输入类型设为 `textUri` 或 `textWebUrl`，软键盘自动显示 `.` `/` `:` 等 URL 常用键。

## 五、保存按钮

保存按钮是第 3 个焦点目标，提供一种"不用软键也能保存"的操作路径：

| 状态 | 行为 |
|------|------|
| 是否可聚焦 | 是，方向键可选中 |
| 焦点态视觉 | 蓝色高亮文字 + 蓝色边框（与 KeydroidxMenuFragment 特殊入口一致） |
| 确认键 | 校验 → 保存 → 回到 S1 |
| 左软键「保存」 | 与保存按钮确认键等同 |

> 保存按钮和左软键「保存」是两条等价的保存路径。
> 即使光标在名称/网址字段上，左软键也直接保存（不需要先移到保存按钮）。

## 六、保存校验

保存时执行以下校验，任一失败则弹出 Toast 提示，不离开页面：

| 校验项 | 规则 | 失败提示 |
|--------|------|---------|
| 名称为空 | 去除首尾空格后长度 = 0 | 「请输入显示名称」 |
| 网址为空 | 去除首尾空格后长度 = 0 | 「请输入网址」 |
| 网址格式 | 必须以 `http://` 或 `https://` 开头 | 「网址需以 http:// 或 https:// 开头」 |

> 校验通过后：去除名称和网址的首尾空格，构造 `KeydroidxWidgetItem(type=TYPE_URL)` 并写入 `KeydroidxWidgetStorage`。

## 七、添加模式 vs 编辑模式

| 维度 | 添加模式 | 编辑模式 |
|------|---------|---------|
| 入口 | S6 → 选「网址」 | S1 → 确认键（光标在网址类组件上） |
| Bundle | `mode=ADD` | `mode=EDIT, editIndex=N` |
| 标题 | 「添加网址」 | 「编辑网址」 |
| 名称字段初始值 | 空（显示占位符） | 当前组件的名称 |
| 网址字段初始值 | 空（显示占位符） | 当前组件的 URL |
| 光标初始位置 | `focusIndex=0`（名称字段） | `focusIndex=0`（名称字段，方便快速修改名称） |
| 保存操作 | `storage.addItem(item)` → S1 | `storage.updateItem(editIndex, item)` → S1 |
| 右软键 | 回到 S6（不保存） | 回到 S1（不保存） |

## 八、按键行为速查

### 全局（所有状态下）

| 按键 | 行为 |
|------|------|
| 左软键「保存」 | 校验 → 保存 → 回到对应上级页面 |
| 右软键「返回」 | 不保存，回到对应上级页面 |

### 焦点态（光标在字段或按钮上，EditText 未激活）

| 按键 | 行为 |
|------|------|
| 上 | 移到上一个焦点目标 |
| 下 | 移到下一个焦点目标 |
| 确认键 | 在字段上 → 激活 EditText；在保存按钮上 → 保存 |

### 编辑态（EditText 激活）

| 按键 | 行为 |
|------|------|
| 方向键 | 无效果（焦点锁定） |
| 回车/完成键 | 关闭软键盘，回焦点态 |
| 物理返回键 | 关闭软键盘，回焦点态 |

## 九、数据流

```
进入页面
  │
  ├─ 如果编辑模式：从 arguments 取 editIndex，读取当前组件数据，预填字段
  ├─ 标题根据模式设置
  └─ 设置焦点到第一个字段

用户保存
  │
  ├─ 校验名称和网址
  ├─ KeydroidxWidgetItem(type=TYPE_URL, payload=URL, label=名称)
  ├─ 添加模式 → storage.addItem(item)
  ├─ 编辑模式 → storage.updateItem(editIndex, item)
  └─ exitCurrent → 回到对应上级页面
```
