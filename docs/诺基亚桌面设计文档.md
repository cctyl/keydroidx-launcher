# 诺基亚风格安卓桌面（Keydroidx Desktop Launcher）设计文档

> 版本：v0.2（草案，基于 2026-07-27 讨论，所有开放问题已闭环）
> 代码基线：基于 J2ME-Loader（J2meLoader fork），模块 `:app`
> 目标设备：带物理按键的安卓手机（方向键 / 左右软键 / 确认键 / 数字键）

---

## 1. 目标概述

本应用的目标是成为一个**诺基亚风格的全功能安卓桌面启动器（Launcher）**，并作为系统默认 Home 桌面运行。核心诉求：

1. **外观**：模仿诺基亚 S40/S60 风格——顶部状态栏 + 中间内容区 + 底部软键栏。
2. **融合 J2ME 与安卓**：将 J2ME-Loader 已安装的 JAR 应用与安卓原生应用**视觉上无缝融合**，但 JAR 只在「百宝箱」中展示，不混入功能表。
3. **物理按键优先**：方向键导航 + 左右软键 + 确认键，所有可选项都可被方向键选中并高亮，最大程度模拟真机。
4. **功能对等**：桌面上的联系人、信息、通话记录等入口映射为安卓系统功能。
5. **真实系统信息**：顶栏显示真实信号（含双卡）、WiFi、电量、运营商、时间。
6. **通知展示**：读取系统通知并展示在桌面指定区域，支持滚动与清除。
7. **按键音**：按下物理按键时播放提示音。
8. **可配置**：提供桌面设置入口 + 复用 J2ME-Loader 自身设置入口；快捷栏可编辑。

## 2. 整体架构

### 2.1 页面模型（基于现有 Fragment 结构）

当前已有三个 Fragment：`KeydroidxDesktopFragment`（桌面）、`KeydroidxMenuFragment`（功能表）、`KeydroidxBoxFragment`（百宝箱），容器为 `KeydroidxDesktopActivity`。基于此扩展：

```
KeydroidxDesktopActivity (singleTask, HOME/DEFAULT Launcher)
├── TopBar (RecyclerView/自定义 View)         ← 真实信号/WiFi/电量/时间
├── Content Area (Fragment 容器)               ← 切换以下页面
│   ├── KeydroidxDesktopFragment   桌面：快捷栏 + 通知区
│   ├── KeydroidxMenuFragment      功能表：第1页系统功能 / 第2页+ 安卓应用
│   ├── KeydroidxBoxFragment       百宝箱：所有已安装 JAR
│   ├── KeydroidxShortcutEditFragment  快捷栏编辑（新增）
│   ├── KeydroidxSettingsFragment  桌面设置（新增）
│   └── KeydroidxNotificationFragment? 通知全屏查看（可选）
└── BottomBar (左软键 / 中键 / 右软键)         ← 绑定到当前页面上下文
```

页面切换规则：
- 桌面「功能表」软键 → 进入 `KeydroidxMenuFragment`。
- 功能表「百宝箱」格子 → 进入 `KeydroidxBoxFragment`。
- 功能表「桌面设置」格子 → 进入 `KeydroidxSettingsFragment`。
- 功能表「设置」格子 → 跳转安卓原生设置（`android.provider.Settings.ACTION_SETTINGS`）。
- 任意页面按挂机/返回键 → 回桌面。

### 2.2 导航焦点系统（核心）

新增一个**统一焦点管理**组件（建议 `KeydroidxFocusManager` 或在每个 Fragment 内实现 `Focusable` 接口），负责：
- 维护当前页面内所有可聚焦项的二维网格顺序（上/下/左/右）。
- 接收 `KeyEvent`（DPAD 方向键），计算下一个焦点并高亮。
- 接收 `KEYCODE_DPAD_CENTER` / `KEYCODE_ENTER` → 触发选中项 `onClick`。
- 接收左右软键 `KEYCODE_SOFT_LEFT` / `KEYCODE_SOFT_RIGHT` → 映射到当前页面底栏动作。

> 复用并扩展现有的 `javax.microedition.lcdui.keyboard.KeyMapper` 与 `ru.playsoftware.j2meloader.settings.KeyMapperActivity` 的按键码枚举，避免重复造轮子。

## 3. 各模块详细设计

### 3.1 顶部栏（Top Bar）— 重构为真实状态

当前 `keydroidx_top_bar.xml` 为静态占位，需改为动态刷新：

- **运营商名**：`TelephonyManager.getNetworkOperatorName()`（每卡一个，显示在对应信号行右侧）。
- **WiFi**：`WifiManager` / `ConnectivityManager` 监听 `WIFI_STATE` 与 RSSI。
- **电量**：`BroadcastReceiver` 监听 `ACTION_BATTERY_CHANGED`，显示百分比 + 充电图标。
- **时间**：`TextClock` 或每秒刷新，含日期。
- 建议新建 `StatusBarController` 统一管理上述数据源并在 `KeydroidxDesktopActivity` 中驱动 `TopBar` 刷新。

### 3.2 桌面（KeydroidxDesktopFragment）

布局：上半部「快捷栏」`shortcutBar` + 下半部「通知区」。

**快捷栏 `shortcutBar`**：
- 数据来自 Room 表 `desktop_shortcuts`（新增），保存用户选定+排序后的应用列表，**同时支持安卓应用和 J2ME JAR**（`type` 字段区分来源：`android` / `jar`）。
- 横向可滚动排列，每个格子显示应用/JAR 图标 + 名称，方向键可横向移动选中，确认键启动对应应用。
- 底栏：左软键=「编辑」（进入 `KeydroidxShortcutEditFragment`）/ 中键=「功能表」/ 右软键=「联系人」（`ContactsContract` 或 `Intent.ACTION_VIEW` 通讯录）。

**通知区**（见 §3.7）。

### 3.3 功能表（KeydroidxMenuFragment）— 分页设计

**分页策略（已确认）**：
- **第 1 页（固定系统功能）**：信息、联系人、通话记录、日历、相册、影音天地、相机、设置（安卓原生）、桌面设置（新增）、百宝箱、安装应用。图标使用内置诺基亚风格 drawable。
- **第 2 页起**：通过 `PackageManager.getInstalledApplications` + 过滤 `Intent.ACTION_MAIN`/`CATEGORY_LAUNCHER` 枚举的安卓应用，分页网格展示，方向键跨页滚动。
- **JAR 应用不出现在此**，统一收口到「百宝箱」。

交互：
- 方向键网格导航，选中高亮；确认键启动。
- 底栏：左软键=「选择」/ 右软键=「退出」(回桌面) / 中键=当前项默认动作。
- 第 1 页系统功能条目 → 跳转对应安卓 Activity / Fragment：
  - 信息：`Intent.ACTION_VIEW` 短信收件箱 或 `Telephony.Sms` 相关。
  - 联系人：通讯录 App。
  - 通话记录：`Intent.ACTION_VIEW` call log。
  - 日历：日历 App。
  - 相册：图库 `Intent.ACTION_PICK`/图库包。
  - 相机：`MediaStore.ACTION_IMAGE_CAPTURE`。
  - 设置：安卓系统设置。
  - 桌面设置：`KeydroidxSettingsFragment`。
  - 百宝箱：`KeydroidxBoxFragment`。
  - 安装应用：触发现有 `InstallerDialog`（安装 JAR）。

### 3.4 百宝箱（KeydroidxBoxFragment）— 仅 JAR

- 数据源：`AppRepository`（Room `apps` 表）的 `LiveData<List<AppItem>>`，与现有 `AppsListFragment` 同源。
- 展示：图标（`Drawable.createFromPath(item.getImagePathExt())`）+ 名称，方向键列表/网格导航。
- 启动：复用 `Config.startApp(activity, item.getTitle(), item.getPathExt(), false)`。
- 长按/左软键菜单：可删除、重命名、查看属性（复用现有 `AppsListFragment` 逻辑）。
- 底栏：左软键=「选项」/ 右软键=「返回」。

### 3.5 快捷栏编辑（KeydroidxShortcutEditFragment）— 新增，诺基亚风格

- 进入方式：桌面左软键「编辑」。
- **可选应用来源**：安卓已装应用（`PackageManager` 过滤 LAUNCHER 入口）+ 已安装 JAR（`AppRepository` 查询 `apps` 表）。两个来源混合显示在同一列表中，用标签/图标微徽区分来源。
- 布局：左半「可选应用列表」+ 右半「当前桌面快捷栏」。
- 诺基亚风格操作：方向键选择 → 左软键「添加/移除」→ 确认键移动排序 → 右软键「完成」保存。
- 保存：写入 Room 表 `desktop_shortcuts`（`type` = `android` / `jar`）。
- 限制：最大快捷项数（如 12），超出提示。

### 3.6 设置

区分两个入口（已确认）：
- **「桌面设置」**（功能表内）：`KeydroidxSettingsFragment`，包含：
  - 按键映射（跳转/复用 `KeyMapperActivity`）。
  - 快捷栏管理（跳转 §3.5）。
  - 通知读取开关（跳转系统通知监听授权，见 §3.7）。
  - 按键音开关（见 §3.8）。
  - 壁纸/主题（后续扩展）。
  - J2ME-Loader 设置入口（跳转现有 `SettingsActivity`）。
- **「设置」**（功能表内，安卓原生）：`Intent(android.provider.Settings.ACTION_SETTINGS)`。

> `SettingsActivity`（J2ME-Loader 自身）保留并可通过「桌面设置」进入，不应在桌面上直接暴露为普通图标。

### 3.7 通知区（KeydroidxDesktopFragment 下半部）

通知区复用桌面现有 `notificationArea`（即 `shortcutBar` 下方、「无更多备忘」所在区域），**非固定高度，采用「快捷栏优先、剩余空间给通知」的策略**：

- **空间分配规则**：快捷栏高度为 `wrap_content`（取决于快捷项图标大小+边距），通知区占用其下方到 `deco_rings` 水印之间的全部剩余空间。屏幕越高通知区越大；屏幕低矮时通知区自动收缩，内容超出时内部滚动。
- **布局实现**：将 `shortcutBar` 与 `notificationArea` 之间改为 `ConstraintLayout` 或 `LinearLayout`（`android:layout_weight="1"` 分配给通知区），确保通知区动态填满剩余高度。
- **权限**：新建 `KeydroidxNotificationListener extends NotificationListenerService`，在 `AndroidManifest.xml` 注册；首次进入时若未授权，引导用户到 `Settings.ACTION_NOTIFICATION_LISTENER_SETTINGS`。
- **数据**：监听 `onNotificationPosted` / `onNotificationRemoved`，存入内存 + 持久化（可选 Room `notifications` 表），含：包名、标题、文本、图标、时间戳。
- **展示**：显示应用图标 + 标题 + 摘要；超出通知区高度时自动垂直滚动（`NestedScrollView` / `RecyclerView`），方向键上下浏览。
- **清除**：全局「清除全部」按钮（在通知区顶部或底栏映射），调用 `NotificationListenerService.cancelNotification` 或本地移除。
- 限制：最多保留 N 条（如 20），超出丢弃最旧；仅显示未屏蔽应用。

### 3.8 按键音

- 方案：使用安卓系统内置按键音。安卓系统自带 `AudioManager.playSoundEffect(AudioManager.FX_KEY_CLICK)`，直接调用即可，无需自备 ogg 资源，也不需要 `SoundPool`。
- 触发：在 `KeydroidxDesktopActivity.dispatchKeyEvent()` 中拦截所有 `ACTION_DOWN` 按键事件，调用 `audioManager.playSoundEffect(AudioManager.FX_KEY_CLICK)`。
- 开关：由「桌面设置」中的「按键音」控制，状态持久化到 `SharedPreferences`。
- 音量：由 `AudioManager` 的 `STREAM_SYSTEM` 音量通道控制，与系统触摸反馈音量一致。

## 4. 数据模型

### 4.1 新增 Room 表
| 表名 | 字段 | 用途 |
|------|------|------|
| `desktop_shortcuts` | `id`, `package_or_path`, `type`(android/jar), `title`, `icon_path`, `sort_order` | 桌面快捷栏配置 |
| `notifications` (可选) | `id`, `pkg`, `title`, `text`, `icon`, `post_time` | 通知缓存 |

### 4.2 复用现有
- `apps` 表（`AppItem`）：百宝箱 JAR 列表。
- `SharedPreferences`：按键映射、按键音开关、通知授权标记。
- `AppRepository`：`getApps()` / `observeApps()` 提供 JAR 数据。

## 5. Launcher 集成（关键改动）

`KeydroidxDesktopActivity` 在 `AndroidManifest.xml` 的 intent-filter 需从：
```xml
<action android:name="android.intent.action.MAIN" />
<category android:name="android.intent.category.LAUNCHER" />
```
追加：
```xml
<category android:name="android.intent.category.HOME" />
<category android:name="android.intent.category.DEFAULT" />
```
并设置 `android:launchMode="singleTask"`（已是）。这样按 Home 键会回到本桌面，安装后系统询问「始终/仅此一次」选择本 Launcher。

> `MainActivity` 维持现状（LAUNCHER 分类当前已被 `KeydroidxDesktopActivity` 占据，`MainActivity` 无 LAUNCHER），不提供任何入口进入，仅保留代码。

## 7. 实现路线（建议阶段）

1. **阶段一 · Launcher 化**：Manifest 加 HOME/DEFAULT，验证可作为默认桌面；保留 MainActivity 无入口。
2. **阶段二 · 顶栏真实化**：StatusBarController 实现信号/WiFi/电量/时间/双卡。
3. **阶段三 · 焦点系统**：FocusManager + 方向键/软键导航 + 高亮，先打通桌面与功能表。
4. **阶段四 · 功能表分页**：系统功能页 + 安卓应用枚举分页；系统功能跳转。
5. **阶段五 · 百宝箱**：绑定 AppRepository + Config.startApp 启动 JAR。
6. **阶段六 · 快捷栏编辑**：Room 表 + 编辑 Fragment + 桌面绑定。
7. **阶段七 · 通知区**：NotificationListenerService + 展示/清除。
8. **阶段八 · 按键音 + 设置整合**：系统 `FX_KEY_CLICK` + 桌面设置页 + 入口区分。

## 8. 已闭环的开放问题

| 问题 | 决策 |
|------|------|
| 快捷栏是否允许放 JAR | **是**，`desktop_shortcuts` 表 `type` 字段支持 `android` / `jar`，快捷栏编辑页面两种来源混合展示 |
| 双卡信号 UI 布局 | **上下分层**：卡 1 信号行在上、卡 2 在下，每行 = 5 格信号条 + 运营商缩写，单卡仅显示一行，符合诺基亚风格 |
| 通知区与快捷栏空间分配 | **快捷栏优先**（`wrap_content`），通知区动态占剩余高度（`layout_weight`），超出时内部滚动 |
| 按键音资源 | **使用安卓系统内置** `AudioManager.FX_KEY_CLICK`，无需自备 ogg |
