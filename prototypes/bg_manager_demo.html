「后台管理」组件 · 交互原型

仅演示界面布局与操作逻辑，非真实 Android 代码

一、入口设计

  • 桌面组件设置中新增组件类型 「后台管理」，添加后桌面出现一行：图标 + 「后台管理」 + 右侧实时后台进程数（如「3 个后台」）。
  • 方向键选中该行 → 确认键 → 打开后台管理窗口（全屏 Fragment，复用现有页面导航体系，天然支持方向键）。

二、窗口布局

  • 顶部页签：「运行」 / 「受保护」，方向键左右切换。
  • 运行页：列出所有后台任务（图标 + 名称），已保护的行右侧显示绿色 「护」 盾牌标记。
  • 受保护页：列出所有已保护应用，可在此取消保护。
  • 底栏：左软键 = 全部保护（一键保护所有后台），中间标题 = 「后台管理」，右软键 = 清除（清除全部未保护后台）。

三、操作逻辑（已按你的方案 A/A）

  • 确认键：切换保护状态 —— 运行页 = 加入保护名单（显示盾牌）；受保护页 = 移除保护。盾牌实时切换，无需二级菜单。
  • 右软键「清除」：一键清除所有未保护的后台应用，跳过保护名单，Toast 提示「已清理 X 个后台应用」。
  • 左软键：运行页 = 「全部保护」；受保护页 = 「全部解除」。
  • 返回键：退出后台窗口回桌面，桌面组件行的后台数同步刷新。
  • 保护名单持久化：存于设置存储，重启不丢；系统关键进程（桌面自身 / 输入法 / midlet 等）永远内置保护，不可清除。

四、按键映射

键盘 ▲▼ / 点击方向键移动高亮焦点
键盘 ◀▶ / 点击方向键切换「运行 / 受保护」页签
Enter / OK 键确认键：切换保护状态
Q 键 / 左软键按钮全部保护 / 全部解除
E 键 / 右软键按钮清除（跳过保护名单）
Backspace / 返回按钮返回桌面
